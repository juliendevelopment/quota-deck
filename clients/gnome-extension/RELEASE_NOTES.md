# QuotaDeck GNOME 0.1.0

Initial independent GNOME Shell 49/50 client. This branch is an unofficial alpha, not an extensions.gnome.org publication.

- Native panel/menu and GTK4/libadwaita account, appearance and privacy preferences.
- Claude PKCE/profile-only OAuth; Codex bounded device-code authorization; Antigravity Google PKCE/local callback with explicit scope disclosure; explicit existing OpenCode Go key entry.
- Direct quota reads, remaining windows/resets, missing/stale readings and safe allowlisted diagnostics.
- Async HTTP/Secret Service, no plaintext credential fallback, no model/purchase/billing/project-creation calls and no other-app credential imports.
- Separate fixture/native/GTK/keyring/headless-Shell verification and deterministic installable packaging.

No real provider account is authorized by build/tests. Consent and real quota acceptance remain user-run desktop checks. Android is unchanged; GNOME release tags use gnome-v* only.
